# Fiscal Analytic

Sistema de gestão de folha de pagamento desenvolvido como projeto de estudo em HTML, CSS e JavaScript.

## Sobre o projeto

O Fiscal Analytic é um projeto pessoal em desenvolvimento, criado com o objetivo de praticar fundamentos de desenvolvimento web aplicados ao contexto de tecnologia contábil e folha de pagamento.

Atualmente, o projeto possui uma interface de dashboard e um formulário para cadastro de funcionários.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
